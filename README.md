# Kanban Board

A modern and responsive Kanban Board application designed to help users efficiently manage tasks and projects. The application provides an intuitive drag-and-drop interface for organising tasks across multiple stages, making project management simple and productive.

## 🚀 Tech Stack

* **Frontend:** React.js
* **Backend:** Next.js with TypeScript
* **Database:** MongoDB

## ✨ Features

* Drag-and-Drop Task Management
* Create, Update, and Delete Tasks
* Organise Tasks Across Multiple Boards and Columns
* Responsive and User-Friendly Interface
* Type-Safe Backend Development with TypeScript
* Efficient Data Storage and Management using MongoDB
* Fast and Scalable Architecture powered by Next.js

## 📂 Project Structure

## 🛠️ Installation

### Clone the Repository

```bash
git clone <your-repository-url>
cd Kanban-Board
```

### Install Dependencies

```bash
# Frontend
cd frontend
npm install

# Backend
cd ../backend
npm install
```

### Configure Environment Variables

Create a `.env` file inside the backend directory and add the following variables:

```env
MONGODB_URI=your_mongodb_connection_string
PORT=3000
```

### Run the Application

#### Frontend

```bash
npm run dev
```

#### Backend

```bash
npm run dev
```
